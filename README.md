# traffic-miniprogram — 商家 & 业务员小程序

UniApp（HBuilderX）开发的微信小程序，包含商家端和业务员端两个角色。

---

## 一、环境要求

| 工具 | 说明 |
|------|------|
| HBuilderX | 4.0+，[下载地址](https://www.dcloud.io/hbuilderx.html) |
| 微信开发者工具 | 最新版，[下载地址](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) |
| 后端服务 | 需要先启动 traffic-backend |

---

## 二、配置后端地址（必须修改）

打开 `utils/request.js`，将 `BASE_URL` 改成后端地址：

```js
// 在同一台电脑上调试时用 localhost：
export const BASE_URL = 'http://localhost:8080'

// 手机真机测试时改成局域网 IP（手机和电脑须在同一 WiFi）：
// export const BASE_URL = 'http://192.168.x.x:8080'
```

**查看本机局域网 IP：**
- macOS：终端执行 `ipconfig getifaddr en0`
- Windows：命令提示符执行 `ipconfig`，找"IPv4 地址"

---

## 三、在 HBuilderX 中运行

1. 打开 HBuilderX
2. **文件 → 导入 → 从本地目录导入**，选择本文件夹（`traffic-miniprogram`）
3. **运行 → 运行到小程序模拟器 → 微信开发者工具**

> 第一次运行会自动打开微信开发者工具，需提前安装并登录。

---

## 四、在手机上真机测试

1. 微信开发者工具右上角点击 **预览**，扫描二维码
2. 在开发者工具 **详情 → 本地设置** 中勾选 **不校验合法域名**
3. 确保 `BASE_URL` 已改为局域网 IP

## 七、常见问题

**Q：手机上接口请求失败 / 显示"网络连接失败"**
1. 确认 `BASE_URL` 填的是局域网 IP，不是 `localhost`
2. 确认手机和电脑在同一 WiFi
3. 确认后端服务正在运行（手机浏览器打开 `http://192.168.x.x:8080` 应有响应）
4. 微信开发者工具勾选"不校验合法域名"

**Q：商家登录提示"手机号或密码错误"**
A：确认该账号在管理后台已被审批通过（status=1）。管理后台 → 商家管理 → 找到对应商家 → 审批通过。

**Q：AI 建议生成时提示"管理员尚未配置大模型"**
A：需要在管理后台（traffic-admin）完成 AI 模型配置，参见 traffic-admin 的 README。

**Q：AI 建议生成超时**
A：国内访问 OpenAI 可能较慢，建议优先使用 DeepSeek 或 MiniMax 等国内服务商。

**Q：HBuilderX 提示 appid 未配置**
A：打开 `manifest.json`，在"微信小程序"一栏填入你的微信小程序 AppID。测试时也可在微信开发者工具中使用测试号，无需真实 AppID。

**Q：图片上传后在手机上显示不出来**
A：图片访问依赖 `BASE_URL`，手机测试时确保 `BASE_URL` 填的是局域网 IP 而非 localhost。
